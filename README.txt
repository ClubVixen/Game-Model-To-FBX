Portable Marvel Rivals users: extract the whole release folder, install Blender,
run RivalsFbxConverter.exe, set Blender and the installed game's Content/Paks,
add unpacked mod packages with their companion files, choose an output folder,
and click Convert batch. Output FBXs are in each job's FBX folder.

The multi-game GUI runs separately from source with python multigame_gui.py.
Developer evidence and automation context: for-llms/README.md.
