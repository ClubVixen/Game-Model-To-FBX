Game Models to FBX — unified Windows application

Extract the entire ZIP and run GameModelsToFBX.exe.
Pick the Marvel Rivals, Deadlock, Zenless Zone Zero or Koikatsu tab along the top.
Use Create / Edit configuration to set your paths, add inputs, Inspect / Read Mods, then Convert Batch to FBX.
Blender and game-specific tools are installed separately.
Read README.md and docs/games/ for each game.
Source launcher: python app.py
